# Clean source delivery index

- `SOURCE_VERSION.txt` — release identity
- `PACKAGE_IDENTITY.json` — machine-readable identity
- `CLEAN_SOURCE_SHA256.txt` — approved archive checksum
- `SOURCE_LAYOUT.md` — canonical source layout
- `SOURCE_TREE_RULES.md` — ownership and duplication rules
- `SOURCE_PACKAGE_CONTENTS.md` — inclusion/exclusion rules
- `CLEANUP_CHANGELOG.md` — cleanup changes
- `VALIDATION_RESULTS.md` — executed source gates
- `SOURCE_BUILD_MATRIX.md` — verified/not-run matrix
- `BUILD_SOURCE_POLICY.md` — release acceptance policy
- `tools/` — extraction, cleanup, verification, and Windows build wrappers
